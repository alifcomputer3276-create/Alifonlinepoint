PUBLISH WITH GITHUB PAGES
1. Open the repository Code tab.
2. Upload the files above to the repository root.
3. Commit changes.
4. In Settings > Pages select Deploy from a branch, branch main, folder /(root).
5. Wait for deployment, then click Visit site.
