ALIF ONLINE POINT — WEBSITE FILES
=================================

Files in this folder:
- index.html             Main website page
- style.css              Responsive black/blue styling
- logo.svg               Vector logo used in header and footer
- application.html       Online application assistance request form
- application-form.css   Request form styling

PREVIEW ON YOUR COMPUTER
1. Keep all files in the same folder.
2. Double-click index.html to open it in a browser.
3. Click Online Application to open application.html.

PUBLISH WITH GITHUB PAGES
1. Open the repository's Code tab.
2. Upload all five website files above to the repository root (not inside another folder).
3. Commit the changes.
4. In Settings > Pages select Deploy from a branch, branch main, folder /(root).
5. Wait for deployment, then click Visit site.
