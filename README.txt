ALIF ONLINE POINT WEBSITE
========================

Files:
- index.html           Main website page
- style.css            Responsive black-and-blue premium design
- application.html     Online application assistance request form
- application-form.css Styling for the request form

HOW TO PREVIEW:
1. Keep all four files in the same folder.
2. Double-click index.html to open it in your browser.
3. Click Online Application to open application.html.

GITHUB PAGES:
1. Upload index.html, style.css, application.html, and application-form.css to the root of the repository.
2. Commit the files.
3. In Settings > Pages select Deploy from a branch, main, /(root).
