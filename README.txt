ALIF ONLINE POINT WEBSITE
========================

Files:
- index.html : website content and page structure
- style.css  : responsive black-and-blue premium design

HOW TO OPEN:
1. Keep index.html and style.css in the same folder.
2. Double-click index.html to preview in your browser.
3. Edit index.html in Notepad or VS Code to change text.
4. Edit style.css to change colors, spacing, and layout.

BEFORE PUBLISHING:
- Replace [গোবরচাপা বাজার, বদলগাছী, নওগাঁ]
- Replace [01610-003276]
- Replace [সকাল ৮ টা থেকে রাত ৮ টা]
- Verify the service descriptions.

NOTES:
- This is a static HTML/CSS website. A contact form, payment system,
  or application submission backend is not included.
- Google Fonts are loaded from the web. If there is no internet connection,
  the page uses local fallback fonts.
- To publish, upload both index.html and style.css to a static hosting service.
