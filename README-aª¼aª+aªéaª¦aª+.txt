ALIF ONLINE POINT — WEBSITE SETUP
================================

ফাইলসমূহ
--------
index.html       ওয়েবসাইটের মূল পেজ
style.css        ডিজাইন ও মোবাইল responsive layout
script.js        ফোন, পেমেন্ট নম্বর ও Google Forms লিংক বসানোর সেটিংস
assets/logo.svg  ওয়েবসাইটের লোগো

১) ফোন নম্বর ও পেমেন্ট নম্বর যোগ করা
----------------------------------
১. script.js ফাইল Notepad দিয়ে খুলুন।
২. ফাইলের শুরুর দিকে SITE_SETTINGS অংশ খুঁজুন।
৩. নিচের খালি quotation-এর মধ্যে আপনার সঠিক তথ্য লিখুন:

phone: "আপনার ফোন নম্বর",
whatsapp: "880 দিয়ে শুরু WhatsApp নম্বর",
bkash: "আপনার bKash নম্বর",
nagad: "আপনার Nagad নম্বর",

উদাহরণ হিসেবে দেওয়া নম্বর ব্যবহার করবেন না; নিজের সঠিক নম্বর বসাবেন।

২) Google Forms লিংক যুক্ত করা
------------------------------
অনলাইন আবেদন:
১. Google Forms (forms.google.com) খুলে Blank Form নিন।
২. নাম, মোবাইল নম্বর, সেবার ধরন, প্রয়োজনীয় তথ্য ও মন্তব্যের ঘর তৈরি করুন।
৩. Send/প্রেরণ থেকে লিংক কপি করুন।
৪. script.js-এ applicationFormUrl: "" এর quotation-এর মধ্যে লিংক বসান।

পেমেন্ট তথ্য জমা:
১. আরেকটি Google Form তৈরি করুন।
২. নাম, মোবাইল নম্বর, পেমেন্ট মাধ্যম, টাকার পরিমাণ, Transaction ID ও প্রয়োজনে রসিদের ছবি চাওয়ার ব্যবস্থা রাখুন।
৩. ফর্মের লিংক কপি করে paymentFormUrl: "" এর মধ্যে বসান।

ফর্মের লিংক অবশ্যই https:// দিয়ে শুরু হতে হবে।
এই ওয়েবসাইটের বাটন Google Form খুলবে; ফরমের উত্তর Google Forms-এই জমা হবে।

৩) GitHub Pages-এ প্রকাশ
------------------------
১. GitHub-এ আপনার repository খুলুন।
২. Add file > Upload files নির্বাচন করুন।
৩. এই ফোল্ডারের index.html, style.css, script.js, README-বাংলা.txt এবং assets ফোল্ডার আপলোড করুন।
৪. Commit changes চাপুন।
৫. Settings > Pages-এ যান।
৬. Build and deployment-এ Deploy from a branch নির্বাচন করুন।
৭. Branch: main এবং Folder: / (root) নির্বাচন করে Save করুন।
৮. কয়েক মিনিট পর GitHub Pages-এর দেওয়া URL খুলুন।

গুরুত্বপূর্ণ
-----------
- আপনার দোকানের ঠিকানা ওয়েবসাইটে যুক্ত করা আছে:
  পাহাড়পুর রোড, গোবরচাপা বাজার, বদলগাছী, নওগাঁ।
- ফোন, WhatsApp, bKash/Nagad নম্বর ও Google Forms URL এখনো দেওয়া হয়নি,
  তাই সেগুলো ইচ্ছাকৃতভাবে খালি রাখা হয়েছে। সঠিক তথ্য script.js-এ বসাতে হবে।
- Google Fonts ব্যবহারের কারণে অনলাইন থাকলে বাংলা ও ইংরেজি ফন্ট আরও সুন্দর দেখাবে;
  ইন্টারনেট না থাকলেও ওয়েবসাইটের মূল কনটেন্ট দেখা যাবে।
